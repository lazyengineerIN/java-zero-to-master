# Java: Zero to Master

Code from **The Lazy Engineer** videos on YouTube: [@LazyEngineerHQ](https://www.youtube.com/@LazyEngineerHQ).

Learn Java from zero. Every example here appears in a video, and every program was compiled and run on Java 25.

## Run an example

You need [JDK 25](https://jdk.java.net/). Open a folder, then:

```bash
javac Main.java
java Main
```

Use the file's own name if it isn't `Main.java`. Each folder's `expected.txt` shows what the program should print.
